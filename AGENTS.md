# AGENTS.md

## Project context

- This project is a public Composer library.
- Versioning is done with Git tags.
- Prefer small, focused changes that match the existing project style.

## General instructions

- Follow existing code style and naming conventions.
- Do not reformat unrelated code.
- Do not introduce new dependencies unless explicitly requested.
- Keep documentation changes concise and relevant.

## Before commit suggestions

When asked to review changes before commit, inspect the unstaged files and answer:

1. Read existing `README.md` if present and say whether it needs to be updated.
2. Read existing `UPGRADE.md` if present and say whether it needs to be created or updated.
3. Suggest a commit message following the style of previous commit messages.
4. If this is still a Composer library using Git tags, check existing Git tags and suggest the next release tag.

## Communication

- Be concise.
- Mention assumptions when relevant.
- Do not mention the attached context unless it is needed for the answer.
